
# Jalaun Community Library Website

This is a simple website created for **Jalaun Community Library (Orai, Uttar Pradesh)** to provide information about the library, its facilities, activities and gallery.

The website helps students easily explore the library online.

---

## 🌐 Live Website

Visit the website here:

https://anandkumar012.github.io/library-website/index.html

---

## 📚 Features

- Library introduction
- Facilities information
- Photo & video gallery
- Contact information
- Terms & Conditions page
- Privacy Policy page
- Responsive design for mobile and desktop

---

## 🛠 Technologies Used

- HTML
- CSS
- GLightbox (for gallery popup)
- Google Fonts
